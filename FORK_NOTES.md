# Local fork notes

This is a reference snapshot of [anthropics/skills](https://github.com/anthropics/skills), based on commit `57546260929473d4e0d1c1bb75297be2fdfa1949`. It is not advertised as the latest upstream release. Preserve the original attribution and each skill's license; the document skills have different terms from the Apache-licensed examples.

The local safety patch in `skills/skill-creator/scripts/package_skill.py` rejects symbolic links and paths resolving outside the selected skill before packaging. It checks files again when reading, builds into a temporary archive, and replaces the output only after successful completion. Existing archives survive validation or read failures. Select an output directory outside the source skill so the archive cannot include itself.

The regression tests use temporary dummy files and do not access private user data. They require Python 3.10+ and the packager's existing PyYAML dependency:

```sh
python -m unittest discover -s skills/skill-creator/tests -v
```

Review upstream changes before syncing this fork, preserve these protections, and rerun the safety tests after a merge. Do not automatically publish archives generated by an unreviewed upstream update.
